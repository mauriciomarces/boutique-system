## Recomendación editorial

Antes de entregar una tesis o exposición, alinear el README raíz, el README de AI y el README del correlador con el código vigente; distinguir el informe histórico de V2 del reporte V3; y anexar resultados de pruebas con su comando, runtime, fecha, conjunto sintético/real y alcance. No editar la memoria académica hasta que el equipo autorice las correcciones y se contraste el documento completo.
