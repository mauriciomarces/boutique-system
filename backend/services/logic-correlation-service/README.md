# Logic Correlation Service

Microservicio responsable de la correlación lógica y temporal de eventos relevantes del sistema.

- Tecnología prevista: NestJS + TypeScript.
- Puerto previsto: 4007.
- No posee base de datos propia en esta arquitectura inicial.
- Preparará características estructuradas para el componente de inteligencia artificial.

La implementación funcional se realizará en la iteración correspondiente a eventos y correlación.
