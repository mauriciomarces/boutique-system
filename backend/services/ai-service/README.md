# AI Service

Microservicio responsable del componente de inteligencia artificial para la preparación de datos, entrenamiento, evaluación y predicción mediante Árbol de Decisión.

- Tecnología prevista: Python + FastAPI.
- Puerto previsto: 8000.
- Base de datos: ia_db (`boutique_ia`).
- Bibliotecas previstas: pandas, numpy, scikit-learn y joblib.

La implementación funcional se realizará en la iteración correspondiente al desarrollo del modelo de IA.
